# 宠伴 - 新手养宠物助手

一款专为新手宠物主人设计的小程序/网站，帮助您轻松照顾爱宠。

## 功能特色

- **首页**: 宠物信息、今日任务、养护小贴士
- **服务中心**: 日常护理、训练中心、健康中心、宠物商店、宠友社区、招聘求职
- **个人中心**: 用户信息、我的宠物、订单记录、设置

## 技术栈

- React 18 + TypeScript
- Tailwind CSS
- Framer Motion
- React Router
- Webpack
