# 智宠宇宙 - 新手养宠物平台

一款专为新手宠物主人设计的平台，帮助您轻松照顾爱宠。

## 功能特色

- **首页**: 宠物信息、今日任务、养护小贴士
- **每日养护**: 每日打卡、任务管理
- **商城**: 宠物用品选购
- **健康管理**: 症状自查、训练指南、疫苗计划
- **宠物档案**: 宠物信息管理

## 主题系统

- 🐕 **汪星人**: 粉蓝色主题
- 🐱 **喵星人**: 橘色主题

## 在线访问

部署在 Vercel 上，纯静态网站。

## 技术栈

- HTML5 + CSS3 + JavaScript
- 微信小程序
- Vercel 部署
